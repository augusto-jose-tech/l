# 🍔 Burger Demo - Página Institucional

Este é o repositório de uma página web demonstrativa para uma hamburgueria artesanal. O projeto foi desenvolvido para criar uma experiência de usuário moderna, rápida e visualmente atraente, simulando um cardápio online com foco em conversão e usabilidade.

## 🚀 Demonstração

Você pode visualizar o projeto em execução através do link: [Insira o link do Vercel/GitHub Pages aqui]

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3 / Tailwind CSS**: Estilização responsiva e animações.
- **JavaScript (ES6+)**: Manipulação do DOM, funcionamento do carrinho e cálculo de pedidos.

## ✨ Funcionalidades

- **Design Responsivo**: Adaptado para celulares, tablets e computadores.
- **Cardápio Dinâmico**: Visualização de hambúrgueres, bebidas e acompanhamentos.
- **Carrinho de Compras Interativo**: Adicionar, remover e atualizar a quantidade de itens.
- **Integração com WhatsApp**: O botão de finalização envia o resumo do pedido direto para o WhatsApp do estabelecimento.
- **Status de Funcionamento**: Alerta visual dinâmico mostrando se a hamburgueria está aberta ou fechada com base no horário local.
